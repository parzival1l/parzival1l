
### Things I've built

- [**ThreadHop**](https://github.com/parzival1l/threadhop): session manager for coding agents. Indexes every transcript into one SQLite + FTS5 store, searches across projects and agents, and lets any session borrow another's context. · [demo](https://threadhop.parzival.computer)
- [**docket**](https://github.com/parzival1l/docket): dispatch work to any coding agent. A per-repo SQLite task queue with acceptance criteria and dependencies, in a single Rust binary. · [demo](https://docket.parzival.computer)
- [**tidyread**](https://github.com/parzival1l/tidyread): cleans web articles for Instapaper and Kobo, with EPUB/KEPUB output · [npm](https://www.npmjs.com/package/tidyread)
- [**op-anthropic-auth-v2**](https://github.com/parzival1l/op-anthropic-auth-v2): OpenCode 2 plugin for Anthropic OAuth with Claude Pro/Max · [npm](https://www.npmjs.com/package/op-anthropic-auth-v2)
